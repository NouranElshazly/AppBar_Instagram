## ✨ Features

- Instagram-style AppBar with logo, heart, and share icons
- Clean and minimal UI
- Built with Flutter Material Design

---

## 🚀 Getting Started

### Prerequisites

- Flutter SDK installed
- Android Studio or VS Code

### Run the app

```bash
flutter pub get
flutter run
```
